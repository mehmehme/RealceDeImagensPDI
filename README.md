📌 Sobre

Este repositório contém implementações em Python para técnicas de realce de imagem.
A ideia é aplicar transformações que melhorem contraste, brilho e detalhes visuais em imagens digitais.

⚙️ Funcionalidades

Ajuste de brilho e contraste

Aplicação de filtros de realce

Equalização de histograma

Processamento com OpenCV e NumPy

🚀 Tecnologias

🐍 Python 3

📷 OpenCV

🔢 NumPy

▶️ Como usar

Clone o repositório:

git clone https://github.com/seu-usuario/realce-imagem.git
cd realce-imagem
